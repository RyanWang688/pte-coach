PTE Academic 题型指南

考试全程在电脑上进行，约 2 小时，分三部分：口语与写作、阅读、听力，共 22 种计分题型（2025 年 8 月新增 SGD、RTS 两种）。很多题型同时计入两项分数，比如 RS 同时算口语和听力分，WFD 同时算听力和写作分。所以 ★ 标记的题型最值得花时间。题量是大致范围，每次考试会有浮动，具体以 Pearson 官方题型说明为准。

一、口语与写作（约 76–84 分钟）

题型题量时间怎么做 / 关键技巧
Personal Introduction1准备 25 秒 / 说 30 秒不计分，但会发给院校。准备一段固定的自我介绍
★ Read Aloud (RA)6–7准备 30–40 秒 / 读约 40 秒读出屏幕上的文字。流利度和发音比内容更重要：按意群停顿，读错了不要回读；超过 3 秒不出声麦克风会关闭
★ Repeat Sentence (RS)10–12答 15 秒原样复述一句话。计入口语和听力。按意群记忆，宁可漏词也要保持流畅
★ Describe Image (DI)3–4准备 25 秒 / 说 40 秒描述图表或图片。用模板：主题 → 2–3 个关键数据 → 趋势或对比 → 结论。流利度比内容完美更重要
★ Re-tell Lecture (RL)1–2听约 90 秒 / 准备 10 秒 / 说 40 秒复述一段讲座。边听边记关键词，套用模板串起来
Answer Short Question5–6答 10 秒用一个词或几个词回答常识问题
Summarize Group Discussion（新）1–2听讨论 / 作答约 2 分钟概括几个人讨论中的不同观点：话题 → 每个人的观点 → 结论
Respond to a Situation（新）1–2准备约 20 秒 / 说约 40 秒根据情景（例如给老师或同事打电话）作答。礼貌开头 → 说明情况 → 提出请求或方案 → 礼貌结束
Summarize Written Text (SWT)1–210 分钟读一篇文章，写一句话概括（5–75 词，只能有一个句号）
★ Write Essay (WE)120 分钟写 200–300 词的议论文。结构清晰、语法正确、用词多样

二、阅读（约 29–30 分钟）

题型题量怎么做 / 关键技巧
★ R&W Fill in the Blanks5–6下拉选词填空，计入阅读和写作。考的是搭配、词性和语法，词汇量的作用最大
MC, Multiple Answers1–2多选，选错会扣分。没有把握就只选最确定的一个
Re-order Paragraphs2–3段落排序。先找首句（不含代词或连接词的独立句），再找成对的句子（代词指代、时间顺序、however / this）
★ Reading Fill in the Blanks4–5拖词填空。先判断空格需要的词性，再看搭配
MC, Single Answer1–2单选。性价比低，时间不够时先放掉

三、听力（约 30–43 分钟）

题型题量怎么做 / 关键技巧
★ Summarize Spoken Text (SST)1–2听讲座写 50–70 词总结（10 分钟），计入听力和写作
MC, Multiple Answers1–2多选，选错扣分
Fill in the Blanks2–3边听边填，拼写必须正确
Highlight Correct Summary1–2选出最符合的总结
MC, Single Answer1–2单选
Select Missing Word1–2根据上下文选出被哔声盖住的结尾
★ Highlight Incorrect Words (HIW)2–3边听边用手指着原文跟读，听到不一样的词就点击。点错会扣分
★ Write from Dictation (WFD)3–4听写一句话，计入听力和写作。拼写决定得分，注意复数 -s、过去式 -ed 和冠词

模板

DI 描述图片（40 秒）

This bar chart illustrates the number of international students in Australia from 2015 to 2024. According to the chart, the highest figure is …, while the lowest is …. It is also evident that X increased steadily / fluctuated. In comparison, Y …. Overall, the chart suggests that ….

画线处换成图里的内容。地图、流程图也能套用：把 highest / lowest 换成 the first stage is … then … finally …

RL 复述讲座（40 秒）

The speaker was talking about topic. Firstly, he/she mentioned that keyword 1. Then the speaker discussed keyword 2 and keyword 3. In addition, keyword 4 was also highlighted. In conclusion, the lecture emphasised the importance of topic.

SGD 概括小组讨论

The discussion was about topic. The first speaker argued that …. However, the second speaker believed …, pointing out that …. The third speaker suggested …. Overall, they agreed / disagreed on ….

RTS 情景回应

Hi name, this is …. I'm calling about situation. Unfortunately, problem. I was wondering if we could solution A, or alternatively solution B. Please let me know what works best for you. Thanks so much for your understanding.

SWT 一句话概括

Main idea of the passage, and although supporting point 1, supporting point 2, which conclusion / implication.

公式：主旨 + 连接词（and / while / although / which）+ 2–3 个要点，控制在 30–50 词，只能有一个句号。

SST 讲座总结（50–70 词）

The speaker discussed topic. He/She first explained that point 1. Moreover, point 2. Finally, the speaker concluded that point 3.

WE 议论文结构（200–300 词，4 段）
  1. 开头（40–50 词）：背景 + 改写题目 + 明确表态（In this essay, I will argue that …）
  2. 主体 1（70–80 词）：观点句 → 解释 → 例子（For example, …）→ 小结
  3. 主体 2（70–80 词）：另一个观点或反方观点 + 反驳（However, …）
  4. 结尾（30–40 词）：In conclusion, … 重申立场 + 建议

评分看内容、结构、语法、词汇范围和拼写。用上当天学的学术词（例如 significant、evident、approach）能提高词汇分。
